# Segurança

Este pacote não contém contas ou credenciais e não instala serviços. Os launchers executam comandos configurados pelo usuário; trate catálogos, arquivos `.desktop` e contextos de agentes como código/dados locais confiáveis, não como conteúdo para importar automaticamente de terceiros.

Para reportar vulnerabilidade, use a opção privada de advisories do GitHub caso disponível. Se indisponível, abra uma issue pedindo um canal privado, sem detalhes exploráveis nem dados sensíveis. Nunca cole uma credencial em issue ou pull request.

As verificações publicadas são estáticas e não garantem ausência de vulnerabilidades. Não execute um snapshot de configuração pessoal como instalador completo da máquina.
